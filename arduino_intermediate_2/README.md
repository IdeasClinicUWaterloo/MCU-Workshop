# Welcome to the Synthesizer & Sound Physics Workshop!

This intermediate workshop bridges digital audio theory with embedded microcontroller programming. You will first explore how frequency, amplitude, wave interference, and envelopes shape sound in Audacity, and then program a Seeeduino Nano synthesizer PCB to play multi-note melodies and custom sequences.

# Required Materials

- 1x Seeeduino Nano
- 1x Custom Synthesizer PCB
- 1x USB-C to USB-A Cable
- 1x Speaker Cabinet
- Audacity installed
- Arduino IDE installed
